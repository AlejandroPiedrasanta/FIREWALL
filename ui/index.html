Acerca de

MiniWall — firewall y monitor de red minimalista. Usa el Firewall de Windows para bloquear apps y ETW para medir el tráfico de cada app. Tus datos se guardan solo en este equipo (%APPDATA%\MiniWall).
Mapa: Natural Earth (dominio público). Geolocalización IP: ip-location-db / geo-whois-asn-country (CC0).
